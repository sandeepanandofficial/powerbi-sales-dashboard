## madhav-store-powerbi-dashboard

# Objective
Owner of Madhav Store wants us to help them create a dashboard to track and analyze their online sales across India

# Key Features
- Created interactive dashboards to monitor sales performance.
- Implemented filters, slicers, and drill-down functionality for dynamic analysis.
- Built data models by creating relationships between multiple tables.
- Developed customized visualizations including bar charts, pie charts, donut charts, line charts, maps, and KPI cards.

# Insights Generated
- Identified top-performing states and customer segments.
- Analyzed sales trends across different categories and regions.
- Monitored business performance using key metrics and visual reports.

# Conclusion
- The dashboard enabled efficient sales monitoring and provided actionable insights through interactive reporting and data visualization.
